# 📱 Inventory Management Android App
https://www.youtube.com/watch?v=ZS01EzCEbzM

## 📌 Overview
This project is an Android-based inventory management application developed as part of my Computer Science program. 
Users can create accounts and log in to the application, which provides complete CRUD (Create, Read, Update, Delete) capabilities for inventory management. 
The system uses a local SQLite database to store user information and inventory data, and includes an SMS notification system that alerts users when an inventory item reaches zero in stock. 
The project began in CS 360: Mobile Architecture and Programming, and my CS 499 capstone project allowed me to expand its capabilities, demonstrating my progress in computer science across various domains.

## 🚀 Features
The application includes essential features that enable users to authenticate their identities and manage inventory dynamically, while maintaining data in persistent storage.
Users can add, update, and delete items while the system maintains an organized view of inventory data through a structured interface. 
The application uses SQLite to store data on local devices, enabling the software to operate without requiring any external resources.

## 🛠️ Technologies Used
The project used Java programming language in Android Studio as its development environment while XML served as the tool for creating user interface components.
The project used SQLite for local database management while Android APIs provided functionality for sending SMS notifications and managing user interactions.
